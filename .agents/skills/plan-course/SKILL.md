# Plan course

1. Read config/course.yaml, curriculum/units, learning outcomes, dependencies, and practical requirements.
2. Confirm available weeks, session length, holidays, assessment windows, and cohort constraints.
3. Sequence prerequisites before dependent outcomes and reserve time for retrieval, practice, and remediation.
4. Update the cohort schedule and coverage plan with traceable outcome identifiers.
5. Check the coverage matrix for omissions and unrealistic load.
