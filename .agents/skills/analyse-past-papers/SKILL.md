# Analyse past papers

1. Verify each paper and marking scheme against sources/manifest.yaml.
2. Preserve raw files and store derived text separately.
3. Capture year, session, paper, question, marks, command words, and source location.
4. Map questions to outcomes with an explicit confidence level.
5. Summarize observed coverage and demand without treating trends as guarantees.
6. Flag ambiguous mappings for curriculum review.
