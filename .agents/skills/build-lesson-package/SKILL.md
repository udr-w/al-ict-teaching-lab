# Build a lesson package

1. Select a competency and verify its outcomes and prerequisites.
2. Create the package using the matching layout under content/lessons.
3. Align explanations, examples, activities, checks, practical work, and homework to the outcomes.
4. Provide complete teacher guidance and separate learner-facing answers where appropriate.
5. Record every curriculum and factual source in provenance.json.
6. Run relevant validation and rendering scripts before handoff.

Reuse assets/ and scripts/ when templates or deterministic generation helpers are present.
