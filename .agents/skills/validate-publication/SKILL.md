# Validate publication

1. Identify every artifact included in the publication candidate.
2. Check schema, links, identifiers, curriculum coverage, and source provenance.
3. Verify assessment totals, answer keys, marking guidance, and rubric consistency.
4. Reproduce practical instructions and render output formats.
5. Scan for private learner data, draft markers, unresolved conflicts, and unsupported claims.
6. Report blocking failures separately from warnings and publish only after blockers are resolved.
