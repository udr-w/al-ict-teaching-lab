# Diagnose progress

1. Define the learner, cohort, time window, and intended outcomes.
2. Combine multiple evidence types and note missing or low-quality data.
3. Distinguish curriculum exposure, performance, mastery, and confidence.
4. Identify likely misconceptions without overstating uncertain causes.
5. Recommend measurable interventions and a reassessment point.
6. Keep individual data inside the relevant private student directory.
