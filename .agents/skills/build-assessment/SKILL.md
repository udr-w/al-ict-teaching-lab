# Build an assessment

1. Read assessment-policy.yaml and select explicit learning outcomes.
2. Draft a blueprint covering marks, time, command words, content, and cognitive demand.
3. Write unambiguous questions that match the blueprint.
4. Produce independent answers and marking guidance, including acceptable alternatives.
5. Check totals, internal consistency, accessibility, leakage, and outcome coverage.
6. Store artifacts in the appropriate assessments/ directories.
