# Build a practical

1. Define outcomes, prerequisites, tools, input files, duration, and safety constraints.
2. Write deterministic setup and learner steps.
3. State observable expected results and evidence learners must submit.
4. Include cleanup, reset, troubleshooting, accessibility, and offline alternatives.
5. Reproduce the task in a clean environment and record limitations.
6. Add assessment criteria and answers when the practical is graded.
