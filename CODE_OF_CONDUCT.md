# Code of Conduct

## Our commitment

We want `al-ict-teaching-lab` to be a respectful, welcoming place for teachers, students, developers, and contributors.

## Expected behaviour

Be constructive, patient, and respectful. Critique ideas and work rather than people. Assume good intent, explain disagreements clearly, and help keep discussions useful to the project.

Do not harass, insult, threaten, discriminate against, or deliberately embarrass others. Do not publish private information, student data, credentials, or security-sensitive details.

## Educational context

This project may contain discussions about teaching, assessment, and learner needs. Treat learner privacy and dignity as non-negotiable. Use synthetic or anonymized examples and never post identifiable student information in issues, pull requests, or discussions.

## Enforcement

Project maintainers may edit or remove comments, commits, issues, pull requests, or other contributions that violate these expectations, and may temporarily or permanently restrict participation when necessary.

If you experience or observe unacceptable behaviour, report it privately to the project maintainer. For security or privacy-sensitive matters, follow `SECURITY.md`.

## Scope

This code applies in project spaces and whenever someone is publicly representing the project.
