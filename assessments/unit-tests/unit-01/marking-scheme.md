# Marking scheme: Unit 1 Checkpoint

Apply positive marking. Accept equivalent technically correct wording and justified alternatives.

## Q1 [6]

a. Values are data/recorded observations (1); the mean is information because the values were processed (1) for the supervisor’s stated purpose (1).

b. Addition of the four values (1); division by four (1); clear explanation connecting either operation to the output (1).

## Q2 [6]

a. Any two valid problem–consequence pairs, two marks each: missing date may cause attendance on the wrong day; missing location leaves scope unclear; missing duration prevents planning; missing issuer reduces verifiability. [4]

b. Any two relevant additions from date, affected systems/location, duration/end time, issuer/contact, or user action. [2]

## Q3 [8]

a. Any two analysed limitations, two marks each: slow aggregation, transcription risk, inconsistent procedures, delayed cross-site reconciliation, difficult retrieval or audit. [4]

b. Coherent digital/hybrid recommendation (1); explained benefit such as rapid aggregation or retrieval (1); suitable control such as validation, reconciliation, audit trail, access control, or backup (1); explanation of how it limits propagated error (1).

## Q4 [6]

a. Internet as interconnected network infrastructure/protocols (1); Web as linked-resource service using it (1); valid non-Web service such as email or file transfer (1).

b. One benefit such as entry at the work location (1); connectivity constraint (1); suitable response such as offline capture and controlled synchronisation (1).

## Q5 [8]

a. Inputs capacity and occupied seats (1); validation/context such as venue or event (1); subtraction process (1); output available seats (1); named user and decision purpose (1).

b. Identifies invalid negative availability or inconsistent input (1); rejects/flags rather than silently publishing it (1); requests source verification or defines an exception path (1).

## Q6 [6]

a. The warning may remain accurate (1) but lose value because the opportunity to prevent harm may pass (1).

b. Any two: continuous operation, rapid comparison, consistent rule application, automated logging, immediate alert generation. [2]

c. Suitable justified control or responsibility, such as sensor validation, fail-safe alarm, escalation, maintenance, or accountable operator response. [2]

Total: 40 marks.
