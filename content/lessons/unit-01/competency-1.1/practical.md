# Practical: Information-quality audit

## Purpose

Transform a fictional dataset into information and evaluate whether the result is fit for a stated decision.

## Resources

A spreadsheet application or calculator, this page, and a copy of the worksheet. No Internet access or personal data are required.

## Dataset

Fictional library enquiries: Monday 18, Tuesday 24, Wednesday 21, Thursday 27, Friday 20.

## Task

1. Preserve the original values in a clearly labelled table.
2. Calculate the weekly total and daily mean.
3. Identify the highest and lowest recorded days.
4. Create one suitable chart or ordered summary.
5. Write two evidence-based information statements for a librarian planning next week’s help desk.
6. Audit your output for accuracy, completeness, relevance, timeliness, clarity, and fitness for purpose.
7. Record one limitation: explain what the dataset cannot establish.

## Expected results

Total: 110 enquiries. Mean: 22 enquiries per day. Highest: Thursday, 27. Lowest: Monday, 18.

## Validation checklist

- Recalculate the total independently.
- Confirm the mean uses five days.
- Match every chart value to the original table.
- Ensure claims describe the recorded week and do not predict certainty.

## Troubleshooting

If a spreadsheet treats values as text, change the cells to numeric format and re-enter them. If the chart labels are missing, add a day column and select both columns before inserting the chart.

## Safety and privacy

Use only this fictional dataset. Do not substitute real borrowing records, learner names, or identifiable activity logs.
