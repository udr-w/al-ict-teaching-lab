# Homework: Competency 1.1

Use the fictional delivery-time data `32, 28, 35, 30, 25` minutes.

1. Calculate the mean delivery time.
2. State one information claim supported by the data.
3. Explain the manipulation that produced the claim.
4. A manager wants to know whether deliveries met a 30-minute target. Evaluate the result for that purpose.
5. Give two additional data fields that would make the information more useful without identifying any customer.
6. Explain, with an example, the difference between information accuracy and information relevance.
