# Classroom delivery guide: From Data to Useful Information

This guide accompanies the rendered `slides.qmd` deck; it is not intended to be read aloud. Use the slides as prompts while learners do most of the noticing, explaining, calculating, challenging, and revising.

## Timing and preparation

The lesson is allocated five periods. The minute ranges below assume a **40–45 minute period** and are paired with percentages so they can be scaled. Preserve the opening retrieval, the outcome check, and the final individual response when time is short; compress reporting rather than learner thinking.

Prepare the fictional examples in the lesson package, blank paper or mini-whiteboards, and calculators or a spreadsheet for Periods 2 and 4. Never replace the fictional datasets with identifiable learner, attendance, borrowing, or support records.

Use these participation routines throughout:

- Ask the question, give silent thinking time, then invite discussion. Do not accept the first fast answer as the class answer.
- Ask for a reason or evidence after every classification: “For which user and purpose?”
- Invite a second learner to agree, challenge, or improve the answer.
- Keep teacher explanation in short bursts of about three minutes, followed by a learner action.
- When answers differ, treat the difference as something to test against context, not as a speed contest.

## Period 1 — Data and information in context (LO-1)

**Outcome check:** Learners distinguish data from information by naming a user, purpose, and context.

### 1. Curiosity opening — 15% (6–7 minutes)

Display only `31, 27, 29, 35, 30` from the “Notice and wonder” slide.

Say: “Do not calculate yet. Write one thing you notice and one thing you need to know before these values can help anyone.”

Give **8–10 seconds silent wait time**, then 45 seconds for pairs to compare. Ask three pairs for responses. Record questions such as unit, location, date, meaning, user, and purpose without judging them immediately.

If a learner calls the values “temperatures,” respond: “That is a reasonable hypothesis. Which evidence confirms it, and which details are still missing?” This protects the distinction between observation and inference.

### 2. Context reveal and physical choice — 20% (8–9 minutes)

Reveal: “These are daily temperatures in °C recorded from Monday to Friday.” Ask learners to show one of two responses—`D` for data or `I` for information—on paper or with agreed hand signals.

Say: “Choose, but be ready to complete this sentence: ‘For ___, trying to ___, this is ___ because ___.’”

Wait **5 seconds after all responses are visible**. Sample one answer from each position. If learners disagree, change the purpose:

- “A scientist wants the original five readings.”
- “A traveller wants to know which day was hottest.”

Transition: “The values did not change; the question did. That is why context, user, and purpose matter.”

### 3. Build the distinction — 25% (10–11 minutes)

Show “Data and information.” Give the definitions briefly, then ask learners to improve them using the opening example.

Suggested phrasing: “Data are recorded observations or symbols. Information is what data become when they are interpreted or processed to answer a question or support a decision. The label is not attached forever; it depends on use.”

Ask, with **5–7 seconds wait time** after each:

1. “Can data be words, images, or sound? Give an example.”
2. “What has to be added to `28.6` before it becomes useful to a traveller?”
3. “Could a calculated mean still be data for a later investigation? Explain.”

Misconception response—“Data are only numbers”: display or name a fault photograph, a voice recording, and a typed complaint. Ask what each records and how it could be interpreted.

### 4. Paired classification challenge — 25% (10–11 minutes)

Use Worksheet A. Learners answer individually first, then compare justifications in pairs. Assign one partner to identify the **user and purpose** and the other to decide whether the item answers that user’s question; swap roles after item 2.

Circulate and listen for reasoning, not just the words “data” and “information.” Prompt with: “What decision is being made?” and “Has this item answered the question yet?”

Energy reset: after two seated items, ask pairs to stand only when they have a context-dependent example of their own. Hear two examples, then seat the class.

### 5. Individual check and bridge — 15% (6–7 minutes)

Ask: “A bus timetable lists `07:10`. For a route planner building a database, what might it be? For a passenger deciding when to leave, what might it be? Justify both.” Give **20 seconds silent writing time** before taking answers.

Transition to Period 2: “Today we changed usefulness by changing context. Next we will deliberately manipulate values to answer a question.”

**Fallbacks:** With no display, write the five values on the board and reveal context orally. With 25–30 minutes, use Worksheet items 1, 2, and 4 only, but retain the individual check. If the class is hesitant, rehearse the sentence frame chorally once, then return to pair reasoning.

## Period 2 — Manipulating data to create information (LO-2)

**Outcome check:** Learners name a manipulation, perform it transparently, and state a claim that the result supports.

### 1. Retrieval hook — 10% (4–5 minutes)

Ask learners to complete, without notes: “Recorded values become information when…” Give **15 seconds**, pair-check, then hear two versions.

Say: “Today the key test is not whether we can calculate. It is whether the calculation answers a stated question.”

### 2. Human transformation — 20% (8–9 minutes)

Give six volunteers fictional request cards or speak values they can hold on paper: Login 4, Printing 2, Network 1, Login 3, Printing 5, Network 2. Ask the class to direct the volunteers to:

1. classify themselves by request type;
2. sort within groups;
3. total each group;
4. compare the totals.

After each move ask: “What manipulation just happened?” Wait **3–5 seconds** before selecting a learner.

Transition: “The original records are still present, but their arrangement now helps us answer a question.”

### 3. Teacher think-aloud — 25% (10–11 minutes)

Show “Common transformations.” Model a short attendance-style or help-desk example using this sequence on the board:

`question → relevant data → manipulation → checked result → supported claim`

Suggested phrasing: “My question is which day needs the most support. I will total requests by day because a total answers that question. I will check the addition. Then I can say which recorded day was highest—but I cannot claim why it was highest.”

Pause before the calculation and ask: “Would sorting alphabetically answer my question?” Give **7 seconds wait time**, then ask one learner to answer and another to challenge or refine.

Misconception response—“Any processing creates useful information”: offer an irrelevant operation, such as arranging days alphabetically. Say: “The operation is valid, but show me how it helps the stated decision.”

### 4. Collaborative calculation and claims — 30% (12–14 minutes)

Learners complete Worksheet B in groups of three:

- **Calculator:** performs totals.
- **Checker:** recomputes independently and compares with the source table.
- **Interpreter:** writes claims and cites supporting values.

Rotate roles after the daily totals. Midway, call: “Freeze. Point to the original value that supports your current result.” This raises attention and checks traceability.

Question prompts:

- “Which transformation produced this result?”
- “What does the result allow you to say?”
- “What can it not establish?”

Allow **10–15 seconds** for the limitation question; it requires more reasoning than recall.

### 5. Claim clinic — 15% (6–7 minutes)

Read two claims: “Tuesday had the most recorded requests” and “Tuesday is always the busiest day.” Learners vote `supported` or `overstated`, then revise the second claim.

Close with a two-line response: “I manipulated the data by ___. This created useful information because ___.” Collect or scan responses for LO-2.

**Fallbacks:** Without devices, calculate on paper; the learning outcome is about transparent manipulation, not software. If arithmetic fluency blocks reasoning, provide correct totals and ask learners to choose the appropriate manipulation and construct a supported claim. With limited time, calculate only daily totals and preserve the claim clinic.

## Period 3 — Judging information quality (LO-3)

**Outcome check:** Learners evaluate information against named criteria and explain the consequence of a weakness for a user.

### 1. Flawed-message hook — 15% (6–7 minutes)

Display or announce: “The ICT practical has moved to Room 4.”

Say: “Imagine this arrives now. Decide privately: Can you act confidently? What is the first question you would ask?” Give **10 seconds**, then collect rapid questions without answering them.

Transition: “A statement may be factually correct and still fail its user. Quality has several dimensions.”

### 2. Criteria with quick contrasts — 25% (10–11 minutes)

Show “Quality check.” Introduce accuracy, completeness, relevance, timeliness, consistency, clarity, and fitness for purpose in pairs of contrasts, not as a long definition list.

Suggested phrasing:

- “Accurate asks, ‘Does it match reality?’ Complete asks, ‘Are the necessary parts present?’”
- “Relevant asks, ‘Does this help this user’s question?’ Timely asks, ‘Did it arrive while action was still possible?’”
- “Fitness for purpose is the overall judgement for this user and decision.”

After each contrast, give a micro-example and ask learners to identify the failing criterion. Use **3 seconds wait time** for recognition and **7 seconds** when asking for consequences.

Misconception response—“Accurate means high quality”: say, “An accurate notice about yesterday’s room change arrives today. What is strong? What fails? What happens to its value?”

### 3. Information-quality carousel — 30% (12–14 minutes)

Place or read three fictional notices:

- accurate but undated;
- current but missing a location;
- complete but intended for another class.

Groups use the structure: `criterion → evidence → consequence for user → improvement`. Rotate examples every 3–4 minutes or pass papers if movement is impractical.

Give roles: reader, criterion finder, consequence challenger, recorder. Ask the challenger: “Would that consequence really follow for the stated user?”

Energy/pacing change: keep the rotations brisk, then lower your voice and slow the room for the final written judgement.

### 4. Repair and defend — 20% (8–9 minutes)

Learners rewrite the practical-room notice using fictional details, then exchange it with another pair. The receiving pair identifies one strength and one remaining ambiguity.

Ask: “Could we keep adding detail forever?” Wait **8–10 seconds**. Guide learners to the idea that completeness means sufficient for purpose, not maximum length.

### 5. Individual quality check — 10% (4–5 minutes)

Prompt: “A report is accurate and complete but three years old. A manager will use it to allocate computers next week. Name the strongest quality concern, explain its consequence, and recommend one improvement.”

Transition to Period 4: “Next, you will create information and audit your own product, rather than only criticising someone else’s.”

**Fallbacks:** If printing is unavailable, project or read notices twice and assign one per group. For language support, provide the frame “It lacks/is weak in ___ because ___. This could cause ___. Improve it by ___.” If time is short, use two notices and retain the individual check.

## Period 4 — Practical information-quality audit (LO-2, LO-3, LO-4)

**Outcome check:** Learners preserve source data, document transformations, make bounded claims, audit quality, and explain value for the stated user and purpose.

### 1. Decision brief and roles — 10% (4–5 minutes)

Open `practical.md` and state the decision: a librarian is planning next week’s help desk using one fictional week of enquiry counts.

Say: “Your product must help this user, but it must also reveal what one week cannot prove. A polished chart is not enough.”

Pairs assign a first **operator** and **auditor**, switching halfway. The auditor checks every result against the preserved source values.

### 2. Predict before operating — 10% (4–5 minutes)

Learners inspect the values without calculating and predict the highest day and an approximate mean. Ask: “What will you check after the software or calculator gives an answer?”

Wait **8 seconds**. Seek checks such as five-day divisor, source-value matching, and independent recalculation.

### 3. Build and verify — 35% (14–16 minutes)

Learners complete Practical tasks 1–4. Circulate using prompts rather than corrections:

- “Show me your untouched source data.”
- “How did you verify the total?”
- “Does the chart label both day and quantity?”
- “If I saw only this chart, what might I misunderstand?”

At the midpoint call a **90-second audit pause**: operators stop; auditors match each displayed value to the original and confirm that the mean uses five days. Then switch roles.

Misconception response—“The spreadsheet result must be correct”: deliberately ask whether a formula dividing by four would look plausible. Require learners to inspect the formula or show the arithmetic.

### 4. Evidence-to-claim challenge — 25% (10–11 minutes)

Learners complete tasks 5 and 7. Put this claim on the board: “Thursday will always require the most staff.”

Say: “Underline the word that exceeds our evidence.” Give **5 seconds**, then ask pairs to rewrite the claim so it is bounded to the recorded week.

Follow with: “Useful to whom, for which decision, and at what time?” Learners annotate each claim with an intended use. This directly checks LO-4.

Energy reset: pairs swap one claim with neighbours for a rapid `supported / overstated / unclear` verdict.

### 5. Quality audit and handoff — 20% (8–9 minutes)

Learners complete task 6 using `criterion → evidence in our product → improvement needed`. Require at least one genuine improvement rather than seven uncritical ticks.

Close with a verbal handoff: one learner plays the librarian and asks, “What should I know, and how confident should I be?” The partner responds in 30 seconds with one supported finding and one limitation.

**Fallbacks:** With no spreadsheet, use calculators or hand calculations and draw an ordered summary instead of a chart. With one device per group, rotate operator, checker, and interpreter roles. If technology fails, award priority to reasoning, preserved calculations, claims, and audit evidence. If learners finish early, ask how a second week could confirm or challenge the initial pattern; do not invite unsupported prediction.

## Period 5 — Apply, assess, and reflect (LO-1, LO-2, LO-3, LO-4)

**Outcome check:** Learners independently connect classification, transformation, quality, and contextual value.

### 1. Retrieval grid — 15% (6–7 minutes)

Without notes, learners divide a page into four boxes labelled:

1. data or information in context;
2. one data manipulation;
3. one quality criterion;
4. user, purpose, and value.

Give **60 seconds silent recall**, then 60 seconds to add or correct in pairs using a different colour or mark. Sample answers quickly; do not reteach yet.

### 2. Worked-example dialogue — 20% (8–9 minutes)

Show the “Worked example” slide with fictional help-desk requests.

Ask in sequence:

- “Which statements are direct calculations?” (**3–5 seconds wait**)
- “Which is an interpretation from comparison?” (**5 seconds**)
- “What wording keeps the claim within the evidence?” (**8–10 seconds**)
- “Who could use this, and for what decision?” (**8–10 seconds**)

Suggested phrasing: “Total and mean are calculated results. ‘Tuesday has the highest recorded demand’ interprets a comparison. The word ‘recorded’ matters because three days do not prove a permanent pattern.”

### 3. Independent assessment — 35% (14–16 minutes)

Learners complete Worksheet D independently. Keep teacher prompts procedural only: “Read the stated user and purpose,” or “Use a quality criterion in your answer.” Do not supply content.

For learners needing access support, read the question aloud, allow speech-to-text or a scribe according to normal classroom arrangements, and preserve the same reasoning demand.

### 4. Feedback through answer improvement — 20% (8–9 minutes)

Use `answers.md` to reveal success features one at a time. Learners annotate rather than erase their first response:

- circle the user or purpose;
- underline the quality criterion;
- box the evidence or example;
- add one missing consequence or improvement.

Ask learners to compare their answer with the criteria, not with a neighbour’s mark. Address misconceptions briefly:

- If “old means inaccurate,” respond: “It may describe the past accurately. Which criterion concerns its use next week?”
- If “more data always improves information,” ask: “More of which data, for which decision, and at what cost?”

### 5. Exit reflection and forward link — 10% (4–5 minutes)

Use the slide prompt: “Give one example of accurate information that would still be of little value because it is irrelevant or late.” Require an example, user, and consequence.

Then ask learners to finish: “One way context changes the value of information is…” Collect responses and sort them after class into:

- secure across all four outcomes;
- secure in classification/transformation but weak in quality evaluation;
- needs retrieval on user, purpose, and context.

Say: “Our next work will build from these distinctions. Keep asking what the data mean, who needs the result, and whether it is fit for the decision.”

**Fallbacks:** If the period is shortened, reduce the worked-example discussion to two questions but keep the independent assessment and exit reflection. If many learners are not secure, model one new example and schedule retrieval rather than turning the assessment into a teacher-led completion. If learners are already secure, require them to construct a case where the same information product has high value for one user and low value for another.

## After-lesson evidence notes

Record brief, non-identifying evidence after each period:

- **LO-1:** Can learners justify a classification using context, not merely repeat definitions?
- **LO-2:** Can learners connect a stated question to a suitable manipulation and bounded claim?
- **LO-3:** Can learners distinguish criteria and explain consequences, not merely list labels?
- **LO-4:** Can learners explain how user, purpose, and time change information value?

Use this evidence to choose the next retrieval prompt or grouping. Do not record learner names or personal data in the public lesson package.
