# Modelling Information Tasks

## The abstraction

Input → Process → Output

## Make each part specific

- Input: which data, units, and constraints?
- Process: which transformation or rule?
- Output: which information, for whom, and why?

## Test the model

Is anything missing? Is the rule valid? Can exceptions occur? Does the output answer the question?

## Time value

Information has high value while it can influence the intended decision. Accurate but late information may be useless for that decision.

## Is a computer appropriate?

Consider volume, repetition, required speed, consistency, storage, cost, human judgement, exceptions, and consequences of error.

## Exit prompt

Give one task where human judgement should remain part of the process.
