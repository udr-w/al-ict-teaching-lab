# Worksheet: Model and evaluate an information task

1. Create an input–process–output model for calculating the total cost of three items including a stated tax rate.
2. Explain why “numbers → computer → result” is an inadequate model.
3. A model calculates an average travel time but does not state the unit or number of journeys. Identify two weaknesses and their consequences.
4. Compare the time value of a flood warning, yesterday’s bus arrival estimate, and a five-year population trend.
5. Explain how information can remain accurate but lose value.
6. Evaluate computer suitability for: adding 10,000 transaction values; resolving a sensitive disagreement; storing a searchable catalogue; choosing an emergency action from incomplete reports.
7. Improve this model: “marks → average → pass list.” State at least four missing details or controls without using real learner records.
