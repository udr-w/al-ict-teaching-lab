# Worksheet: Selecting technology for information work

1. Explain how increasing record volume can affect the speed of a manual workflow.
2. Distinguish unreliability from inaccuracy using one example each.
3. Explain why automating an incorrect rule does not improve information quality.
4. Classify each as an Internet infrastructure component/function, a Web activity, or another Internet service: a router forwarding Internet packets; opening a linked page; sending email; following a hyperlink.
5. Explain the relationship between the Internet and the World Wide Web.
6. A mobile survey team uses portable devices and a cloud service where connectivity is intermittent. State two benefits, two constraints, and two controls. For each, identify whether it concerns mobile computing, mobile communication, cloud computing, or more than one.
7. A club processes twelve membership renewals per year. Recommend a manual, digital, or hybrid method and justify it against scale, accuracy, retrieval, and cost.
8. A clinic must distribute an urgent public notice widely. Explain how merging information and communication technologies helps, without using patient data.
9. Choose one domain such as transport, agriculture, health, education, or disaster response. Explain how information supports one decision, forecast, plan, survey, or monitoring task and name a suitable dissemination technology.
