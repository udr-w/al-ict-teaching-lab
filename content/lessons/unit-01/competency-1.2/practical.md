# Practical: Compare manual and digital workflows

## Purpose

Compare two methods using measured evidence rather than assumptions.

## Dataset

Fictional request codes: `P, N, P, L, N, P, N, N, L, P, L, N, P, P, N, L, N, P, L, N` where P = printing, N = network, and L = login.

## Task

1. Tally each category manually and record elapsed time.
2. Enter the codes in a spreadsheet, use a counting function or filter, and record elapsed time.
3. Compare both totals and investigate any difference.
4. Repeat after adding twenty copied records.
5. Evaluate speed, accuracy, reproducibility, setup effort, and suitability at each scale.
6. Recommend a manual, digital, or hybrid workflow.

## Expected results

Original totals: P = 7, N = 8, L = 5; total records = 20. Results after duplication depend on the added records and must be verified against the expanded list.

## Validation checklist

Preserve the source list; confirm category totals sum to the record count; repeat one count independently; distinguish measured time from opinion.

## Troubleshooting

Remove leading spaces if identical codes count differently. If a formula range omits rows, select the complete populated column and recalculate.

## Safety and privacy

Use only fictional codes. Do not substitute support tickets, usernames, or identifiable service records.
